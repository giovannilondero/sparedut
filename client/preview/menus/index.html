Spec #20 · menu prototypes

Sparedût

Three throwaway prototypes of the home screen and room creation, with the game's own texts. Each one switches between Friulian and Italian, and every screen has its own address. Draw a phone-sized window (portrait and landscape) before judging the desktop. Esc goes back one screen.

A · Stepwise

Home is four big choices. The room list is one level down, with join by code. Creation is a guided sequence: mode, map, options, then a summary with the create button.

B · Compact page

Home shows everything at once, the room list included. Creation is one page: mode and map in front; duration, bots, skill, reach, access and friendly fire folded under "options".

C · List as home

The room list is the home screen, with join by code above it and the two ways to play under the thumb. Creation opens as a side panel, a bottom sheet on an upright phone.
